\begin{frame}{Backup: how is stability calculated?}
  \small
  In repeat $b$, we compare the same retained cell IDs $R_b$:
  \[
    J_{c,b}=\max_j\frac{|(C_c\cap R_b)\cap D_{j,b}|}{|(C_c\cap R_b)\cup D_{j,b}|},
    \qquad S=\frac{1}{K}\sum_{c=1}^{K}\operatorname{median}_b J_{c,b}.
  \]
  $C_c$: original cluster; $D_{j,b}$: new cluster on retained cells.
  \begin{itemize}
    \item 10 repeats; retain 80\,\% within each donor, without replacement.
    \item Refit scaling and clustering; method parameters stay fixed.
    \item Absent clusters: NaN. At least 6 assessable repeats in the current run.
    \item No minimum size; a singleton can be stable when retained.
  \end{itemize}
  \takeaway{This measures robustness within the initial sample, not generalisation to new donors.}
  \source{Our notebook implementation; reference assignments are not ground truth.}
\end{frame}
